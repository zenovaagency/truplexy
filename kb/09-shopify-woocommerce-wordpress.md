# Truplexy — Shopify, WooCommerce and WordPress

## How does the Shopify integration work?
Install the Truplexy app on your Shopify store from the dashboard. It adds a chat window on every storefront page and lets the assistant look up order status and search products. Orders are read for signed-in customers, with the permissions you approve when you connect.

## What can the assistant do in a Shopify store?
It has two built-in read-only tools: order status and product search. Turn them on under Tools in the dashboard. The assistant cannot change orders.

## How do I set up the Shopify chat?
Connect the store from Integrations → Shopify. How the chat window looks is set under Integrations → Chat widget.

## How does WordPress work?
Download the Truplexy Chat plugin (truplexy-chat.zip). In WordPress open Plugins → Add New → Upload Plugin, choose the zip, click Install Now, then Activate. The plugin opens its settings page: paste your chat key and save. The page says Connected when the key works. The plugin adds the chat to every page by itself, so you don't edit your theme.

## Does it work on WooCommerce?
Yes. It is the same plugin. For a store, also connect the WooCommerce store in the dashboard so the assistant can look up orders and products, then turn the two lookups on under Tools. Order lookups work for signed-in customers.

## Where do I set the colour and greeting?
In the dashboard under Integrations → Chat widget: title, greeting, colour, picture and position. There are 8 colour presets plus a custom colour.

## Are Shopify, WooCommerce and WordPress on every plan?
Yes. They are included on Starter, Pro and Enterprise.
